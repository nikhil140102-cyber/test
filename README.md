# test

Flutter app generated by App Builder.

## Quickest way to run it

- **Windows:** double-click **`run_windows.bat`**
- **Mac / Linux:** open Terminal in this folder and run `./run_mac_linux.sh`

The script sets everything up, runs the automatic checks and starts the app.

Full step-by-step instructions, Android Studio and VS Code steps, and fixes for
common problems are in **[HOW_TO_RUN.md](HOW_TO_RUN.md)**.

## What is in this folder

| Path | What it is |
|---|---|
| `lib/main.dart` | App start, theme and page routes |
| `lib/pages/` | One file per page you designed |
| `test/widget_test.dart` | Automatic checks: every page and every navigation button |
| `tool/prepare_android.dart` | Adds the internet permission Android needs for web images |
| `run_windows.bat`, `run_mac_linux.sh` | One-click setup and run |
| `pubspec.yaml` | Package name (`test`) and dependencies |
